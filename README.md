# Бизнес-инсайты

Сервис для руководителя: выбрать компанию, увидеть события, которые относятся именно к ней, и открыть разбор с фактами, рисками, возможностями и источниками.

Папка проекта была пустой: не было ни кода, ни датасетов, ни адреса модели. Поэтому компании, сюжеты и аналитические справки лежат в `backend/data` и явно помечены как демонстрационные. Это не живая лента и не аналитика Альфа-Банка. Позиция банка показывается только если в библиотеке есть документ с признаком `is_bank_research`. В стартовом наборе таких документов нет.

## Почему такой стек

- Python 3.12 и FastAPI: один процесс для данных, правил, проверки качества и API.
- Статический интерфейс без сборки фронтенда: его проще запустить на демо и упаковать в Docker.
- SQLite хранит сводку, разбор, вопросы и журнал вызовов инструментов.
- Поиск по справкам лексический. Эмбеддинги не используются: отдельных моделей для них в списке организаторов нет.
- Языковая модель не вшита. Есть адаптер к OpenAI-совместимому `POST /chat/completions`. Адрес не придуман: пока `LLM_BASE_URL` пустой, работает локальный движок и бюджет модели не тратится.

Релевантность — это сумма весов правил, которые сопоставляют тему сюжета с заполненными полями профиля. Ответ не выбирается из таблицы «компания → готовый текст». Новая компания в JSON получает собственную сводку без правки кода.

## Запуск на Windows

Нужен Python 3.12. Если команда `python` открывает Microsoft Store, установите Python 3.12 и откройте новый терминал.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000

Проверки:

```powershell
python -m pytest backend/tests
```

## Docker

```powershell
docker compose up --build
```

Сервис будет на http://127.0.0.1:8000 в демонстрационном режиме.

## Сценарий демонстрации

1. Откройте сервис. Первой выбрана ООО «Кама Металл».
2. В сводке первая новость — про цену стали. Спортивный сюжет не попадает в список. Повтор про сталь снят как дубль.
3. Откройте новость про сталь. Блок подтвержденных фактов пуст: сведения сюжета не выдаются за внешнюю проверку. Блок аналитики Альфа-Банка говорит, что материал не найден. Ниже лежит демонстрационная справка с явной пометкой. Выводы AI ссылаются на профиль и сюжет. В тексте есть выручка 18,5 млрд ₽ из профиля, но 6% цены на нее не переносятся.
4. Задайте вопрос «Кто бенефициар компании?» — владелец не выдумывается. «Что говорит аналитика Альфа-Банка?» повторяет, что материал не найден.
5. Откройте новость про ключевую ставку. Проверка сама добавляет оговорку: в профиле нет структуры долга. Учебные 16% не выдаются за решение регулятора.
6. Переключитесь на ООО «Городская полка». Первой становится розница, новости про сталь нет. У ООО «Контур Софт» вверху найм ИТ-специалистов. У ООО «Северный эскиз» профиль неполный: в разборе нет выдуманной выручки, а пропуски перечислены отдельно.

## Модель

Разрешены только имена из задания: Gemma 4 26B A4B, GLM-5.3-Flash, Qwen3.6 35B A3B, DeepSeek-V4.1-Flash, Qwen3-VL-30B-A3B-Instruct, Kimi-K2.6. Другое имя блокируется.

```
LLM_BASE_URL=адрес_от_организаторов
LLM_API_KEY=ключ
LLM_MODEL=Gemma 4 26B A4B
LLM_MAX_CALLS=8
```

Модель может только переписать уже собранный разбор. Если в тексте появляются новые числа или необоснованное упоминание Альфа-Банка, формулировка отклоняется. На сводку из восьми карточек вызов не тратится: один раз при открытии события и один раз на вопрос. Лимит в 500 рублей так не выбирается демонстрационным прогоном. Без переменных расход равен нулю.

Живая лента необязательна:

```
NEWS_FEED_URLS=https://example.com/feed.xml
```

Материалы RSS помечаются как непроверенные и не смешиваются с подтвержденными фактами. Если лента недоступна, остается демонстрационный набор.

## Как устроен расчет

Один агент проходит шаги и пишет их в интерфейс: задача, профиль, лента, снятие дублей, ранжирование, документы, черновик, проверка, правка если нужно, сохранение. Между шагами передается JSON. Журнал инструментов пишет только имя шага, идентификаторы и статус. Ключ модели и тело профиля в журнал не попадают.

Правила лежат в `backend/app/services/impact.py`. Каждое правило имеет вес и условие: отрасль, продукт, валюта, контрагент, регион, выручка, группа. Нет данных — правило молчит.

Проверка в `backend/app/services/quality.py` снимает выводы без источника, слишком уверенные формулировки и ложную пометку «подтверждено». Для ставки она требует оговорку о структуре долга, если ее забыл черновик.

## Данные

| Файл | Что внутри |
| --- | --- |
| `backend/data/companies.json` | шесть вымышленных компаний |
| `backend/data/news.json` | учебные сюжеты, включая дубль и нерелевантный матч |
| `backend/data/documents.json` | справки с `is_bank_research: false` |

Чтобы показать найденную аналитику банка, добавьте документ с `"is_bank_research": true` и темами сюжета. Пока признак ложный, интерфейс не называет справку позицией банка.

Секреты только в окружении. Файл `.env` не коммитится, образец — `.env.example`.
